# Taskly Angular

Application Angular de gestion de tâches réalisée pour l'évaluation.

La documentation complète se trouve dans [DOCUMENTATION.md](./DOCUMENTATION.md).

## Lancer le projet

```bash
npm install --legacy-peer-deps
NG_CLI_ANALYTICS=false npm start
```

Puis ouvrir http://localhost:4200/.

## Compiler le projet

```bash
NG_CLI_ANALYTICS=false npm run build
```
